# Planted bugs: mqtt

Written by `python3 tests/plant_bugs.py`. Each plant is a small change to the reader or its rules, put in a scratch copy of the repo. Tests: the harness run against the planted tool, caught when it reports a failure. Proofs: `lake build` with the planted code, caught when the proofs of the approved statements no longer build. Each plant makes the statement named in its row false, and the first failing test input is a witness: the planted reader accepts it, and the statement says no reader that meets it does. So no proof can be repaired to go through. The first row is the control, with no plant: it must pass both.
